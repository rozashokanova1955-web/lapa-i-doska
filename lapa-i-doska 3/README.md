# Лапа и доска

Мастерская мебели для животных (Казахстан): каталог лежанок, будок и когтеточек, конфигуратор с расчётом цены по размерам, заказ онлайн, кабинеты клиента, менеджера, мастера и администратора. Цены в тенге (₸).

## Роли
- **Клиент**: каталог, конфигуратор, заказ, свои заказы и история, согласование цены, отмена до производства.
- **Менеджер**: все заказы, итоговая цена, назначение мастера, учёт оплаты, запуск в производство, выдача.
- **Мастер**: только свои заказы в производстве; этапы чертёж → распил → сборка → покраска → упаковка.
- **Администратор**: изделия, материалы, опции (архив вместо удаления), пользователи и роли, статистика.

## Стек
React 19 + Vite · Node.js 20+ + Express 5 · PostgreSQL + Prisma · JWT + bcrypt · zod

## Запуск
Нужны Node.js 20.6+ и PostgreSQL (создайте пустую базу `lapa_i_doska`).

```bash
cd server
npm install
cp .env.example .env        # впишите DATABASE_URL и JWT_SECRET (≥ 32 символов)
npx prisma migrate dev      # создаёт таблицы
npm run seed                # каталог + тестовые пользователи, пароли печатаются один раз
npm run dev                 # API: http://localhost:4000
```
В другом терминале:
```bash
cd client
npm install
npm run dev                 # сайт: http://localhost:5173
```
Тестовые пользователи (создаёт seed): `admin@lapa.kz`, `manager@lapa.kz`, `master@lapa.kz`, `client@lapa.kz`. Пароли: из `ADMIN_PASSWORD` / `SEED_PASSWORD` в `.env` либо сгенерированные и показанные при `npm run seed`.

Тесты логики цены и статусов: `cd server && npm test` (базу не требуют).

## Как пройти сценарий
1. Клиент: выбрать изделие → «Добавить в заказ» → «Оформить заказ».
2. Менеджер: открыть заказ → задать итоговую цену → «Отправить на согласование».
3. Клиент: «Согласовать».
4. Менеджер: назначить мастера, записать предоплату 50 %, «Запустить в производство».
5. Мастер: отметить 5 этапов, после последнего заказ сам становится «Готов».
6. Менеджер: записать полную оплату → «Выдать клиенту».
